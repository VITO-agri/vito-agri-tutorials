# How to gain access to ASIS data on Google Cloud storage?


[This notebook](https://github.com/VITO-agri/vito-agri-tutorials/blob/main/notebooks/drought/2_asis_data_access.ipynb) demonstrates how to access FAO ASIS data directly from Python scripts.

All data generated by the FAO ASIS system is hosted on a Google Cloud Storage bucket. In order to access these data, you need a Google account (anonymized data access is no longer possible).

This document guides you through the process of setting up Google Authentication service, enabling direct access to the ASIS raster files using rasterio functionality in Python.

This will involve installation of the Google Cloud application, ideally on the system you are using to run your Python scripts. In some instances, for example on the [JupyterLab environment of the Copernicus Data Space Ecosystem](https://dataspace.copernicus.eu/analyse/jupyterlab), it is not possible to install additional applications. In such case, you can install this application on your local system, use it to generate your application credentials (json file) and transfer that file to the system where you are running your Python code.

## Step 1: Install Google Cloud application

Installation is demonstrated here for a Linux-based system. 

Go to your terminal and execute the following command to start the installation of Google Cloud:

    curl https://sdk.cloud.google.com | bash

When asked about the “Installation directory”, you can just accept the default location by hitting Enter.
Installation might take a while. You’ll see a message “Welcome to the Google Cloud CLI!”

When asked whether you want to help improve Google Cloud CLI, type “N” and hit Enter.

When asked to modify your $PATH and enable shell command completion, type “n” and hit Enter.

Installation should be completed now.

Now type and execute this command in your terminal window:

    exec -l $SHELL

Check successful installation of Google Cloud Application by executing the following two commands:

    source ~/google-cloud-sdk/path.bash.inc

    gcloud –version

the last command should print the application version. You can also check whether the “google-cloud-sdk” folder has been added to your installation folder.


## Step 2: Authenticate with your Google Account

Run the following command in the Terminal:

    gcloud auth application-default login

Open the displayed link in your web browser and login with your Google Account.

Copy the generated authentication code and paste it in your terminal window and hit ENTER.

From now on, your google credentials are stored in a json file:
~/.config/gcloud/application_default_credentials.json

Double-check the existence of this file by running the following command in your terminal:

    ls -l ~/.config/gcloud/application_default_credentials.json

## Optional Step 3: Copy credentials

If you have generated your credentials file on a different machine than the one you are using to run your Python scripts, make sure to copy the .json file created in the previous step to that machine.

    cp ~/.config/gcloud/application_default_credentials.json ~/adc.json

You may need to ensure that the file has reading permissions by all users after you copied the file:

    chmod 644 ~/adc.json

## Step 4: Make sure you configure your environment before accessing files on Google Cloud Storage

In any Python script, make sure to execute the following lines of code first (replace adc_path value with the exact path to your credentials json file) that you got as a result from step 2 and 3.

    import os
    # set the path to your Google Application Credentials JSON file
    adc_path = "/home/jeroendegerickx/.config/gcloud/application_default_credentials.json"
    os.environ["GOOGLE_APPLICATION_CREDENTIALS"] = adc_path

    # ensure anonymous mode is off
    os.environ.pop("GS_NO_SIGN_REQUEST", None)

This should allow you now to directly access files using rasterio, e.g.:

    import rasterio
    url = "gs://fao-gismgr-asis-data/DATA/ASIS/MAPSET/PHE/ASIS.PHE.GS1.SOS.LC-C.tif"
    with rasterio.open(url) as ds:
        arr = ds.read(1)
        print(ds.profile)
